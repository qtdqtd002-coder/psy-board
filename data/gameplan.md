# 제작 방향

:::lead
뼈대는 제노니아 1편에서 빌리고, 얼굴은 이 세계의 것으로 만든다. 다섯 장을 한꺼번에 벌이지 않고 1장 하나를 끝까지 만든 다음 넓힌다.
:::

:::facts
만드는 것 | 탑뷰 액션 RPG [확정: 제노니아류]
엔진 | Unity 6.3 LTS, URP [확정: Unity]
첫 목표 | 수직 슬라이스. 1장 첫여울을 처음부터 보스까지
첫 직업 | 메잡이 하나
아트 방식 | [미정] 세 갈래를 견주었다. 추천은 3D 로우폴리 실시간
정할 사람 | 아트 방식, 주인공의 얼굴, 제목, 첫 플랫폼은 사용자가 정한다
:::

:::note 이 글의 표시
사용자가 정한 것은 [확정], 기획이 낸 안은 [제안], 비워 둔 것은 [미정]이다. 제노니아에 대한 서술은 2026년 10월 7일에 출처를 열어 확인한 것만 적었고, 출처는 글 끝에 있다.
:::

## 목표

- 제노니아를 해 본 사람이 "그 맛이다"라고 느끼는 탑뷰 액션 RPG를 만든다.
- 혼자와 AI로 끝까지 만들 수 있는 크기로 짠다.
- 이 게임만의 한 가지를 분명히 한다. 보스를 잡으면 고장이 잃었던 소리가 돌아온다.

## 벤치마크: 제노니아 1편에서 무엇을 가져오나

조사로 확인한 제노니아 1편의 특징을 하나씩 놓고 가져올지, 바꿀지, 버릴지 정했다.

| 제노니아 1편 | 판단 | 이 게임에서 |
|---|---|---|
| 탑뷰 2D 도트. 마을, 들, 굴, 보스로 이어진다 | 가져온다 | 고장마다 마을 하나, 들 두세 곳, 굴 하나, 보스 하나 |
| 고아 주인공. 양아버지를 잃고 까닭을 찾아 떠난다 | 뼈대만 | 우레와 바우. 다만 바우는 죽지 않고 목소리를 잃는다 |
| 맞서는 두 세력. 성당기사단과 용혈족 | 뼈대만 | 종단과 고요회. 어느 쪽도 악이 아니다 |
| 선과 악 성향. 고른 대로 이야기, 동료, 보스가 달라진다 | 바꾼다 | 울림과 고요의 [[기울기]]. 선악이 아니라 서로 다른 두 가지 옳음 |
| 직업 셋. 워리어, 팔라딘, 어쌔신 | 가져온다 | 메잡이, 소리꾼, 길잡이. 첫 빌드는 메잡이만 |
| 낮과 밤 | 가져온다 | 밤에는 종소리가 덜 닿아 더 센 소리먹이가 나온다 |
| 허기, 무게, 내구도 | 버린다 [제안] | 먹거리는 되살림 물약으로만 쓴다. 원작도 내구도는 업데이트로 누그러뜨렸다 |
| 직업별 기술 나무, 수백 가지 장비, 강화 | 줄여서 | 기술 나무는 둔다. 장비는 가짓수를 줄이고 [[조율]]로 깊이를 낸다 |
| 요정 길동무 | 가져온다 | 아리. 보스를 잡을 때마다 소리 하나를 배운다 |
| 애니메이션풍 초상화가 나오는 대화 | 가져온다 | 초상화 대화. 손말과 망치말은 따로 연출한다 |
| 이동은 네 방향. 대각선이 없다 | 바꾼다 [제안] | 여덟 방향 이동. 지금의 조작 기대에 맞춘다 |
| 타격감. 진동, 소리, 밀려남 | 가져온다 | 소리가 주제인 게임이라 맞는 소리와 밀려남에 가장 공을 들인다 |
| 게임 밖을 건드리는 농담 | 바꾼다 | 웃음은 아리가 맡는다. 세계 안에서 웃긴다 |
| 뻔한 선택받은 자 이야기라는 평 | 바꾼다 | 우레는 제비로 뽑혔을 뿐이다. 특별한 것은 그 뒤의 선택이다 |
| 모으고 나르는 곁가지 퀘스트가 되풀이된다는 평 | 바꾼다 | 관계 퀘스트 아홉 갈래와 '잃은 소리 찾기' |
| 분량. 2009년 리뷰는 40시간 넘게, 이용자 후기는 메인 예닐곱 시간 | 줄인다 [제안] | 본편을 짧고 촘촘하게. 정확한 시간은 1장을 만들어 재 본 뒤 정한다 |

:::note 확인하지 못한 것
제노니아 1편의 지역 수와 퀘스트 총수, 타일 크기, 캐릭터 그림의 방향 수는 믿을 만한 출처를 찾지 못했다. 그래서 이 글의 분량과 규격은 제노니아의 숫자를 따르지 않고 따로 정한다.
:::

## 아트 방식: 세 갈래 가운데 고른다

배경, 오브젝트, 캐릭터를 무엇으로 만들지는 이 한 가지 결정에 달려 있다. 요즘 나온 비슷한 게임들이 쓴 방식을 세 갈래로 묶었다.

:::cards 3
가. 3D 로우폴리 실시간 | 추천 | 캐릭터와 배경을 단순한 3D로 만들고 카메라를 위에서 비스듬히 고정한다. Death's Door와 Tunic이 이 방식이다. 모델 하나로 여덟 방향과 모든 동작을 쓴다.
나. 3D를 구워 낸 2D 그림 | 차선 | 3D로 만든 뒤 방향마다 그림으로 구워 2D 게임으로 만든다. 도트풍으로 다듬으면 제노니아의 맛에 가까워진다. 이 방식으로 낸 비슷한 게임은 조사에서 확인하지 못했다.
다. 손으로 찍는 2D 도트 | 원작의 방식 | 제노니아와 CrossCode의 방식이다. 가장 제노니아답다. 그림의 양이 가장 많다.
:::

| 견줄 것 | 가. 3D 실시간 | 나. 구운 2D | 다. 2D 도트 |
|---|---|---|---|
| 캐릭터 하나에 드는 그림 | 모델 하나와 동작 | 모델 하나와 동작, 그리고 굽는 과정 | 방향 수 곱하기 동작 수 곱하기 장면 수 |
| 장비를 바꾸면 겉모습이 바뀌게 하려면 | 쉽다. 갈아 끼운다 | 번거롭다. 다시 굽는다 | 가장 어렵다. 다시 그린다 |
| 낮과 밤, 적막의 어두움 | 조명으로 된다 | 따로 만들어야 한다 | 따로 만들어야 한다 |
| 소리 물결 연출 | 셰이더로 된다 | 2D 효과로 된다 | 2D 효과로 된다 |
| 제노니아의 도트 맛 | 멀다 | 가깝다 | 같다 |
| 혼자와 AI로 만들기 | 맞다. 3D 생성 도구를 이미 갖추었다 | 굽는 틀을 먼저 만들어야 한다 | 어렵다. 지난번 AI 도트는 품질이 모자랐다 |
| 지금의 Unity 뼈대 | 렌더 설정을 3D로 바꿔야 한다 | 지금의 URP 2D 그대로 쓴다 | 지금의 URP 2D 그대로 쓴다 |

:::note 추천은 '가'. 다만 눈으로 보고 정한다
추천하는 까닭은 만드는 양이다. '가'만이 방향 수와 동작 수가 늘어도 그림이 늘지 않는다. 그러나 손맛과 그림의 좋고 나쁨은 숫자로 정할 수 없다. 그래서 시험 한 벌을 먼저 만든다. 우레 하나, 잠잠이 하나, 첫여울의 땅 한 화면을 '가'와 '나' 두 방식으로 만들어 나란히 놓고 사용자가 고른다. 그 전에는 아트를 늘리지 않는다.
:::

## 무엇을 만드나

세계관 문서에서 센 수다. 아트 방식이 정해지면 규격을 채운다.

| 대상 | 전체 | 수직 슬라이스 | 만드는 법 [제안] |
|---|---|---|---|
| 주인공 우레 | 하나. 소임 셋의 무기와 옷 | 메잡이 차림 하나 | 서기, 걷기, 치기 셋, 구르기, 맞기, 쓰러지기, 종 치기 |
| 길동무 아리 | 하나 | 하나 | 단순한 덩이. 반투명한 몸과 속의 불빛은 셰이더로 낸다 |
| 이름 있는 인물 | 열여섯. 우레와 아리는 빼고 | 다섯. 바우, 느티, 달구, 들메, 다래 | 바탕 몸 넷을 만들고 옷과 머리를 바꿔 끼운다. 어른 둘, 아이, 노인 |
| 소리먹이 | 열 가지 | 셋. 잠잠이, 째째, 바스락이 | 몸은 같은 셰이더, 윤곽만 다르게. 삼킨 소리의 임자를 닮는다는 규칙을 따른다 |
| 보스 | 다섯 | 하나. 먹부리 | 보스마다 소리 물결의 모양이 다르다 |
| 고장의 땅 | 다섯 벌 | 한 벌. 첫여울의 숲과 개울 | 고장마다 조각 한 벌. 바닥, 벽과 벼랑, 길, 물, 소품 스물에서 서른 |
| 굴 | 다섯 | 하나. 먹굴 | 고장의 조각을 어둡게 다시 쓴다 |
| 고장의 얼굴 | 종루와 종 다섯 | 첫여울 종루 | 고장마다 생김새가 다른 큰 건물. 멀리서도 보인다 |
| 소리 물결 | 종소리, 공격, 적막 | 셋 다 | 이 게임의 얼굴이다. 종을 치면 물결이 마을 끝까지 번지는 것이 보여야 한다 |
| 화면 | 대화, 가방, 기술, 지도, 상점 | 대화, 가방, 상점 | 초상화를 그림으로 할지 모델로 할지는 [미정] |

### 소리는 그림만큼 중요하다

이 게임은 진행을 귀로 듣게 한다. 그래서 소리를 아트와 같은 무게로 계획한다.

| 소리 | 수 | 쓰임 |
|---|---|---|
| 고장의 배경 소리 겹 | 고장마다 둘. 보스를 잡기 전과 뒤 | 보스를 잡으면 한 겹이 더해진다. 새소리, 망치 소리, 장터 소리, 풍경 소리 |
| 종소리 | 다섯. 여울종, 쇠종, 어미종, 손종, 첫 종 | 고장의 종마다 높이와 길이가 다르다 |
| 적막 | 하나의 처리 | 굴에 들어가면 모든 소리가 먹먹해진다. 높은 소리를 걸러 낸다 |
| 맞는 소리 | 무기와 상대에 따라 | 타격감의 절반이다 |
| 아리의 목소리 | 바우의 말 조각 여남은 개와 아리의 제소리 | 성우를 쓸지는 [미정]. 글자와 효과음만으로도 된다 |

## 구현 방식

Unity에서 짜는 틀이다. 지금 남아 있는 뼈대와 규칙을 그대로 잇는다.

:::cards 2
렌더와 카메라 | URP | 위에서 비스듬히 내려다보는 고정 카메라. 아트 방식이 '가'면 3D 렌더러로 바꾸고, '나'나 '다'면 지금의 2D 렌더러를 쓴다.
땅 | 격자와 조각 | 격자에 맞는 조각을 늘어놓아 고장을 짓는다. 씬과 프리팹은 에디터 스크립트로 만든다. 손으로 고치지 않는다.
데이터 | 번호가 곧 열쇠 | 퀘스트, 대사, 소리먹이, 장비를 데이터로 둔다. 세계관 문서의 번호 M1-01과 S3-2가 그대로 데이터의 열쇠가 된다.
대화 | 말투를 지키는 표 | 인물마다 말투 표를 지킨 대사 표를 둔다. 손말은 손짓 그림과 자막으로, 망치말은 박자로 보여 준다.
소리 | 상태로 켜고 끈다 | 고장의 배경 소리 겹을 보스를 잡았는지에 따라 켜고 끈다. 적막에서는 소리 전체에 거르개를 건다.
갈림 | 기울기와 깃발 | 갈림마다 기울기 값을 움직이고 깃발을 세운다. 4장은 같은 땅을 다른 길동무로 돌려 써서 갈림의 값을 줄였다.
저장 | 종루에서 | 종루에 닿을 때 저장한다. 굴에서는 손종이 임시 저장을 맡는다.
검증 | 테스트가 통과해야 끝 | 싸움의 셈과 퀘스트의 흐름은 Unity와 떨어진 순수한 코드로 짜고 테스트를 붙인다. 손맛은 사람이 해 보고 정한다.
:::

| 단계 | 무엇을 | 끝났다는 표시 |
|---|---|---|
| M0 프리프로덕션 | 세계관과 인물과 퀘스트. 아트 방식 시험과 결정. 회색 상자로 싸움의 손맛 시험 | 사용자가 아트 방식을 고르고, 회색 상자 싸움이 재미있다고 한다 |

## 사용자가 정할 것

| 무엇 | 기획의 안 | 언제까지 |
|---|---|---|
| 아트 방식 | '가' 3D 로우폴리 실시간. 시험 한 벌을 보고 정한다 | 아트를 시작하기 전 |
| 주인공의 성별과 생김새 | 안을 내지 않았다. 게임의 얼굴이라 사용자가 정한다 | 시험 한 벌을 만들기 전 |
| 제목 | 첫울음 | 급하지 않다 |
| 첫 플랫폼 | PC 먼저 | M1 전 |
| 허기, 무게, 내구도를 버리는 것 | 버린다 | 시스템 기획 전 |
| 초상화를 그림으로 할지 모델로 할지 | 아트 방식을 따른다 | 아트 방식이 정해진 뒤 |
| 아리와 바우의 목소리를 성우로 할지 | 글자와 효과음부터 | M2 전 |

## 걸리는 것

- 크기. 메인 서른다섯에 관계 스물일곱은 혼자 만들기에 많다. 1장을 만들어 실제로 걸린 시간을 재고 2장부터의 크기를 다시 정한다.
- 갈림의 값. 3장의 갈림과 세 맺음은 만들 것을 늘린다. 4장을 같은 땅으로 묶어 줄였지만 대사는 두 벌이다.
- 손말과 망치말. 따로 만드는 연출이라 값이 든다. 1장에는 나오지 않으니 M2에서 값을 잰다.
- AI로 만든 모델과 그림. 쓰는 도구의 약관을 먼저 읽는다. Steam에서는 AI 사용을 밝혀야 한다.
- 손맛. 문서로는 재미를 보장하지 못한다. 회색 상자 시험에서 싸움이 재미없으면 세계관이 아니라 싸움부터 고친다.
